## 1012 유기농 배추 풀이 설명

이 문제는 서로 인접한 배추들이 몇 개의 그룹으로 나뉘어져 있는지 구하는 문제이다. 

처음에는 단순히 배추가 있는 위치만 확인하면 된다고 생각했으나, 인접한 배추들을 하나의 그룹으로 묶어야 한다는 점에서 탐색 알고리즘이 필요하다는 것을 파악하였다.

핵심 아이디어는 방문하지 않은 배추를 발견할 때마다 새로운 그룹으로 카운팅하고, DFS로 연결된 배추 전체를 방문 처리하는 것이다. 

모든 칸을 순회하면서 아직 방문하지 않은 배추를 발견하면 answer를 증가시키고, DFS를 통해 상하좌우로 연결된 모든 배추를 방문 처리한다. 

이후 다시 미방문 배추를 만나면 새로운 그룹이므로 answer를 또 증가시킨다.

DFS에서는 현재 칸이 이미 방문했거나 배추가 아니면 즉시 return하고, 그렇지 않으면 방문 표시 후 상하좌우 4방향으로 재귀 탐색한다. 

4방향 이동 시에는 배열 범위를 벗어나지 않도록 조건을 걸어준다.

## 풀이 과정에서의 시행착오`

처음에는 배추가 있는 위치를 하나씩 확인하면서 인접한 배추를 직접 찾는 방식으로 접근하였다. 그러나 배추가 여러 개 연결되어 있는 경우 모든 연결 관계를 추적하기 어렵다는 것을 깨닫고, DFS를 활용한 탐색 방식으로 전환하였다.

DFS 구현 과정에서 배열 범위를 체크하는 조건을 빠뜨려 ArrayIndexOutOfBoundsException이 발생하였다. 상하좌우 이동 전에 각각 r > 0, c > 0, r < ROW-1, c < COL-1 조건을 추가하여 해결하였다.

또한 처음에는 방문 체크 없이 DFS를 구현하였더니 이미 방문한 배추를 다시 방문하여 무한 루프가 발생하였다. visited 배열을 추가하여 한 번 방문한 칸은 다시 방문하지 않도록 처리하였다.

입력 처리에서도 시행착오가 있었다. 문제에서 X가 가로(열), Y가 세로(행)를 의미하는데, 처음에 r과 c를 반대로 입력받아 잘못된 결과가 나왔다. 입력 순서를 A[r][c] = 1에서 X가 c, Y가 r임을 명확히 하여 해결하였다.
