### N과 M 풀이 설명  
먼저 입력받은 N개의 수를 정렬한다. 수열이 오름차순이어야 하고 사전 순으로 출력해야 하므로, 정렬 후 백트래킹으로 탐색하면 자연스럽게 두 조건을 모두 만족한다.

백트래킹 함수는 현재까지 고른 수들의 리스트와 다음 탐색을 시작할 인덱스를 인자로 받는다. 리스트 크기가 M이 되면 현재까지 고른 수열을 출력하고 반환한다. 안그러면 start 인덱스부터 N까지 순서대로 수를 하나씩 골라 리스트에 추가하고 재귀 호출한 뒤 다시 제거하는 방식으로 진행한다.

인덱스를 start부터 시작하게 함으로써 이전에 고른 수보다 뒤에 있는 수만 고르게 되어 오름차순이 자동으로 보장된다. 이미 정렬된 배열에서 인덱스 순서대로 탐색하면 사전 순 출력도 함께 만족된다.

### 풀이 과정에서의 시행착오

1. 오름차순 조건을 직접 비교로 구현하려 한 실수

처음에는 정렬 없이 백트래킹 내부에서 현재까지 고른 수의 마지막 원소와 후보 수를 직접 비교해 오름차순을 검사하려 했다. 이렇게 해도 오름차순 조건 자체는 맞지만, 사전 순 출력을 보장하려면 배열 자체가 정렬되어 있어야 한다. 정렬을 먼저 하면 인덱스 순 탐색만으로 오름차순과 사전 순이 동시에 해결된다는 점을 뒤늦게 깨달았다.

2. visited 배열 방식을 사용하려 한 실수

중복 없는 순열을 구하는 문제와 헷갈려서 visited 배열을 두고 매번 인덱스 0부터 탐색하는 방식을 처음에 작성했다. 이 방식은 순서가 다른 같은 숫자 조합을 별개로 취급하므로 조합이 아닌 순열을 구하게 된다. 오름차순 수열은 결국 조합을 구하는 문제이므로, start 인덱스를 넘겨 항상 이전보다 뒤의 인덱스만 탐색하는 방식이 올바르다.

3. 불필요한 중복 제거 처리

문제 조건에 N개의 자연수가 모두 다른 수라고 명시되어 있어 중복 제거가 별도로 필요하지 않다. 처음에 출력 결과에 중복이 생길까 봐 집합 자료구조로 걸러내려 했으나, 입력 자체에 중복이 없으므로 전혀 불필요한 작업이었다.

4. 출력 형식 실수

수열 내 원소를 공백으로 구분해 출력해야 하는데, 리스트를 그대로 출력하면 대괄호와 쉼표가 포함된 형식으로 나온다. 원소를 하나씩 순회하며 공백과 함께 직접 이어 붙이는 방식으로 출력 형식을 맞춰야 한다는 점을 예제 출력과 대조하면서 발견했다.
