### 문제를 처음 마주쳤을 때 떠오른 아이디어
큐에 넣고 빼기를 반복해서 우선순위가 높은 순서대로 정렬하듯이 한다면 그 해당 인덱스(몇번째였는지)를 같이 저장하면 쉽게 풀 수 있을거라 생각했다.

### 어떤 방식으로 풀기로 했는지
큐가 비지 않을 때까지 반복을 해서

일단 비교할 대상을 하나 뽑고

비교할 대상이 가장 큰 우선순위인지 다른 값들과 우선순위를 비교한다 boolean값으로 일단 만들었다.

큐를 순회하며 우선순위 비교 후 

큰 값이 있다면 큐 맨 뒤에 넣고

만약 없다면 몇개 프로세스가 실행되었는지 세기 위해 count한다.
