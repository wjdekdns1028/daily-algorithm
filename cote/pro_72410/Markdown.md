## 72410 신규 아이디 추천
이 문제는 입력으로 주어진 아이디 문자열이 카카오 아이디 규칙에 맞지 않을 때, 7단계의 순차적인 처리 과정을 거쳐 규칙에 맞는 아이디로 변환하는 문제이다. 각 단계가 독립적이고 순서대로 진행되기 때문에, 단계별로 하나씩 구현하는 방식으로 접근하였다.

먼저 원본 문자열을 새 변수 answer에 복사한 뒤, 각 단계마다 answer를 덮어씌우는 방식으로 진행하였다.

1단계에서는 Java String의 toLowerCase() 메서드를 활용하여 모든 대문자를 소문자로 변환하였다.

2단계에서는 문자를 하나씩 순회하면서 허용된 문자인지 판별하고, 허용된 문자만 모아 새 문자열을 만들었다. 알파벳 소문자와 숫자는 Character 클래스의 isLowerCase(), isDigit() 메서드로, 나머지 빼기, 밑줄, 마침표는 직접 비교로 판별하였다.

3단계에서는 정규식을 활용해 마침표가 1개 이상 연속된 부분을 마침표 하나로 치환하였다.

4단계에서는 startsWith(), endsWith() 메서드로 처음과 끝의 마침표 여부를 확인한 뒤 substring()으로 제거하였다.

5단계에서는 isEmpty() 메서드로 빈 문자열 여부를 확인하고, 빈 문자열인 경우 "a"를 대입하였다.

6단계에서는 길이가 16 이상이면 앞 15자만 남겼다. 이때 자른 후 끝에 마침표가 생길 수 있으므로, 길이 초과 처리 내부에서 한 번 더 끝 마침표를 확인하였다.

7단계에서는 길이가 3이 될 때까지 마지막 문자를 charAt()으로 가져와 반복해서 붙였다.


## 풀이 과정에서의 시행착오
3단계 정규식 작성 과정에서 마침표 패턴을 잘못된 형식으로 작성하였다. 정규식에서 마침표는 특수문자이기 때문에 이스케이프 처리가 필요한데 이를 놓쳤고, 올바른 형식으로 수정하여 해결하였다.

5단계에서는 answer에 대입해야 하는데 원본 매개변수인 new_id에 대입하였다.

7단계에서는 while 조건을 반대로 작성하였다. 길이가 3이 될 때까지 반복해야 하는데 길이가 3일 때 반복하도록 작성하여 아예 실행되지 않는 코드가 되었고, 조건을 수정하여 해결하였다.

6단계에서는 처음에 끝 마침표 제거를 길이 초과 처리 바깥에 두었다. 그러나 4단계에서 이미 끝 마침표를 처리했기 때문에, 여기서 끝 마침표가 새로 생기는 경우는 15자로 자른 후뿐이라는 점을 파악하고 처리 내부로 이동하여 해결하였다.
