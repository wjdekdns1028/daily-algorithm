### 문제를 처음 마주쳤을 때 떠오른 아이디어
우선 남은 진도율을 계산하고 속도로 나누어 각 기능마다 언제 배포가 이루어지는지 계산해야겠다고 생각했다.
그리고 현재 배포 중인 것을 point로 두어 끝난 기능이 point 보다 작은지, 큰지를 비교해 배포가 필요한 갯수를 증가하게 해야겠다고 생각했다.

### 어떤 방식으로 풀기로 했는지
떠오른 아이디어대로 쉽게 구현하기로 했다.

### 그래서 어떤 구조로 작성했는지
사실 처음에 스택/큐 문제인걸 모르고 그냥 풀었다. 그래서 그냥 오랜만에 푸는거니 감 익힐 겸 제한을 두지 않고 풀었다.
ArrayList로 저장하려 했지만 출력할 때 복잡하고 int를 Integer로 박싱하는 과정때문에 메모리, 속도에 불필요하다고 생각해서
그냥 StringBuilder에 저장해 단순하게 출력하였다.

### 풀면서 막힌 부분이나 새롭게 알게 된 점
딱히 막힌 부분은 없었지만 처음으로 point를 day[0]으로 설정할 때 if(i == 0) 라는 조건을 두지 않아 계속 초기화되었었다.
