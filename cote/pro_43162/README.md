### 어떤 방식으로 풀기로 했는지

dfs에서는 우선 방문한 노드는 방문으로 바꾸고 매개변수 배열에서 해당 컴퓨터의 연결을 확인한다

연결되어있고 방문 전이면 그대로 내려간다

그렇게 한 묶음이 완성되면 count를 올리고 아직 방문 전인 노드를 기준으로 다시 시작한다.
