## 6603 로또 풀이 설명
이 문제는 입력으로 주어진 k개의 수를 담고 있는 배열 ar에서 6개의 수를 선택하는 모든 조합을 구하는 문제이다. 이를 해결하기 위해 DFS(깊이 우선 탐색)와 백트래킹을 활용하였다.

먼저 main 함수에서 입력을 받아 int[] ar 배열에 저장한 후,
DFS(ar, 0, new ArrayList<>(), 6);을 호출하여 탐색을 시작한다.
여기서 index는 현재 탐색 중인 배열의 위치를 의미하고, selected는 지금까지 선택된 숫자들을 저장하는 리스트이며, r은 최종적으로 선택해야 할 개수(6개)를 의미한다.

DFS 함수는 다음과 같은 방식으로 동작한다.

static void DFS(int[] ar, int index, List<Integer> selected, int r)

먼저 index >= ar.length인 경우는 배열의 끝까지 모두 탐색한 상태를 의미한다.
이때 selected.size() == r이라면 정확히 6개의 숫자를 선택한 것이므로 이를 출력하고, 그렇지 않다면 아무 작업 없이 종료한다.

이후 현재 위치의 원소 ar[index]를 기준으로 두 가지 경우를 나누어 탐색한다.

첫 번째는 현재 원소를 선택하는 경우이다.

selected.add(ar[index]);
DFS(ar, index + 1, selected, r);

현재 값을 selected에 추가한 뒤, 다음 인덱스로 이동하여 탐색을 계속 진행한다.

두 번째는 현재 원소를 선택하지 않는 경우이다.
이를 위해 먼저 방금 추가한 값을 제거해야 한다.

selected.remove(selected.size() - 1);
DFS(ar, index + 1, selected, r);

여기서 remove는 단순한 삭제가 아니라, 이전 상태로 되돌리는 백트래킹 과정이다.
이 과정을 통해 같은 selected 리스트를 유지하면서도 “선택한 경우”와 “선택하지 않은 경우”를 모두 올바르게 탐색할 수 있다.

이와 같은 방식으로 모든 경우를 탐색하면, 결과적으로 ar 배열에서 6개를 선택하는 모든 조합이 생성된다.

## 풀이 과정에서의 시행착오
처음에는 입력을 배열 ar에 저장하는 과정에서 반복문의 범위를 k-1로 설정하여 마지막 숫자가 누락되는 문제가 발생하였다. 
이로 인해 생성되는 조합이 일부 잘못되었고, 이후 반복문을 i < k로 수정하여 문제를 해결하였다.

또한 초기에는 결과를 출력할 때 System.out.println(selected);를 사용하여 리스트 자체를 출력하였다. 
이 경우 출력 형식이 [1, 2, 3, 4, 5, 6]과 같이 나타나 문제에서 요구하는 공백 구분 형식과 맞지 않는 문제가 있었다. 
이를 해결하기 위해 반복문을 사용하여 각 원소를 공백으로 구분하여 출력하도록 수정하였다.

DFS 구현 과정에서는 selected.remove(selected.size() - 1);의 필요성을 이해하는 데 어려움이 있었다. 
처음에는 값을 추가한 뒤 제거하지 않고 다음 재귀를 호출했는데, 이 경우 이전 선택이 계속 유지되어 잘못된 결과가 나왔다. 
이후 remove를 통해 이전 상태로 되돌리는 백트래킹 과정이 반드시 필요하다는 것을 이해하게 되었다.

또한 처음에는 문제를 한 번의 입력으로만 처리하도록 작성하였으나, 실제로는 여러 테스트케이스가 주어지고 마지막에 k == 0이 입력되면 종료된다는 점을 놓쳤다. 
이를 while 반복문과 종료 조건을 추가하여 해결하였다.
