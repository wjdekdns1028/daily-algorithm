### 문제를 처음 마주쳤을 때 떠오른 아이디어
일단 정수들을 다 돌아서 더하거나 빼야하니 재귀로 돌아야겠다고 생각했다. 숫자마다 선택지가 +랑 -이고 돌아가면서 하나를 기준으로 끝까지 계산해봐야하니 dfs를 사용해야겠다고 생각했다.

### 어떤 방식으로 풀기로 했는지
처음에는 일단 for문으로 무작정 숫자 하나 잡아서 +랑 -로 분기하려 했는데 재귀를 써야하니 일단 dfs 메서드를 만들었다.

dfs니까 depth랑 sum을 만들었고 메서드들에서 공통적으로 써야하니 클래스에 public static으로 선언했다.

dfs 메서드는 간단하게 n개 모두 돌았고, target이 sum과 같다면 count를 하나 올리게 했다.

그리고 재귀를 돌았다 depth는 한 번 돌 때 1씩 더했고 +와 - 모두 한 번씩 돌게 했다.
